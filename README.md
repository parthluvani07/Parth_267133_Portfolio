## 🌟 Key Sections

1. **Home / Hero (`#hero`):** Welcome banner, dynamic typing subtitle, introductory bio, CTA buttons, and responsive profile photo with floating badges.
2. **About Me (`#about`):** Background details, academic qualifications (JG University & GMIU), internships, and core engineering pillars.
3. **Skills (`#skills`):** Categorized competencies in Web Technologies, Programming Languages (C, Java, Python, C++), and Cloud/Databases with animated skill bars.
4. **Experience & Education (`#experience`):** Detailed timeline of internships at Aashro Tech IT Company, Dewtown bootcamps (OpenCV, DSA, DevOps), and academic degrees.
5. **Projects (`#projects`):** Filterable project cards with category filters (*Web Development*, *Front-End*, *Software & Core*) and interactive case study modals.
6. **Contact Me (`#contact`):** Direct contact links, social connectivity, and a fully validated interactive contact form.

---

## ⚙️ JavaScript Working Features (Fulfilling Rubric Requirements)

1. **Dark & Light Mode Toggle:**
   - Switches the color theme between Dark Theme (default) and Light Theme.
   - Saves the user's preference in `localStorage`.
2. **Responsive Mobile Navigation Menu:**
   - Accessible hamburger toggle button (`aria-expanded`) that slides open the navigation menu on mobile and tablet screens.
3. **Interactive Contact Form Validation:**
   - Real-time and on-submit checking of full name, email format, subject, and message.
   - Prevents empty form submission and displays friendly error alerts and a submission confirmation banner.
4. **Dynamic Typing Effect & Stats Counter:**
   - Cycles through professional roles and animates numerical metrics on scroll.
